# Grokking Deep Learning - Code Reproduction & Theoretical Deep-Dive

## Main Objective
This repository is dedicated to deepening the understanding and practical skills in implementing core Machine Learning concepts. It contains code reproductions and structured theoretical deep-dives based on the book **Grokking Deep Learning** by Andrew Trask (Manning Publications).

## Repository Contents & Chapter Summaries

This repository is structured chapter-by-chapter. Below is a general summary of the concepts covered in each chapter:

*   **Chapter 1: Introducing Deep Learning** 
    Explores the fundamental shift from traditional programming to parametric learning, where machines use trial and error to adjust weights and learn patterns from data. (Theoretical concept only, no code).
*   **Chapter 2: Fundamental Concepts: How do machines learn?**
    Introduces the basic building blocks of prediction, focusing on forward propagation and how simple math operations (inputs x weights) form a basic neural network.
*   **Chapter 3: Forward Propagation: Introduction to Neural Prediction**
    Expands on Chapter 2 by demonstrating how networks can predict multiple outputs from multiple inputs using matrices and NumPy.
*   **Chapter 4: Introduction to Neural Learning: Gradient Descent**
    Introduces the core mechanism of learning: measuring error and using Gradient Descent to adjust a single weight to minimize that error.
*   **Chapter 5: Learning Multiple Weights at a Time: Generalizing Gradient Descent**
    Scales the concept of Gradient Descent to multiple weights simultaneously, allowing a network to learn from multiple inputs to make a single prediction.
*   **Chapter 6: Building Your First Deep Neural Network: Intro to Backpropagation**
    Moves from single-layer networks to multi-layer (deep) networks. Introduces the Backpropagation algorithm, allowing the network to calculate error contributions across hidden layers.
*   **Chapter 7: How to Picture Neural Networks**
    Provides a visual and conceptual mental model for neural networks, mapping mathematical matrices into intuitive nodes and edges to better understand correlation and overfitting. (Theoretical concept only, no code).
*   **Chapter 8: Learning Signal and Ignoring Noise: Regularization & Batching**
    Focuses on preventing overfitting. Introduces Stochastic Gradient Descent (Mini-batching) to speed up training, and Dropout (Regularization) to force the network to learn robust features instead of memorizing noise.
*   **Chapter 9: Modeling Probabilities and Nonlinearities: Activation Functions**
    Explains the necessity of non-linear activation functions (like ReLU, Sigmoid, and Tanh) to allow networks to learn complex, non-linear relationships. Also introduces Softmax for probability distribution in classification tasks.
*   **Chapter 10: Introduction to Convolutional Neural Networks (CNNs)**
    Shifts focus to computer vision. Introduces convolutional layers and pooling to reuse weights across different parts of an image, making the network spatially invariant and highly efficient for image processing.
